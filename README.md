# Tornado

## V1 — foundation + playable game loop

Incluye:

- LocalStorage (`tornado_data`, `tornado_context`)
- Home
- Creación de partidas
- Question Mode
- Teacher Mode
- Sets de preguntas
- Equipos ilimitados
- Grid 4x4, 5x5 y 6x6
- Casillas de puntos
- ×2
- ÷2
- SWAP con elección de equipo
- TORNADO
- Turnos
- SHOW ANSWER
- CORRECT / INCORRECT
- Revelación de casillas
- Pantalla de resultados
- Final automático cuando no quedan casillas

Flujo:

QUESTION → SHOW ANSWER → CORRECT/INCORRECT → BOARD → REVEAL → EFFECT → NEXT TEAM

Teacher Mode:

TEACHER → CORRECT/INCORRECT → BOARD → REVEAL → EFFECT → NEXT TEAM
